# One-page setup guide - ASX Paper Trader V4

## GitHub

1. Sign in to GitHub.
2. Create a new repository named `asx-paper-trader-v4`.
3. Public is easiest for testing. Private also works if Streamlit has private repo permissions.
4. Upload every file from this ZIP into the root of the repo.
5. Commit the files to the `main` branch.

## Streamlit Cloud

1. Sign in to Streamlit Community Cloud using the same GitHub account.
2. Create a new app.
3. Repository: `bartwoolley/asx-paper-trader-v4` or your repo name.
4. Branch: `main`.
5. Main file path: `app.py`.
6. Select Deploy.

## After deployment

- Open the app URL.
- Add tickers to watchlists.
- Configure scanner settings.
- Record paper trades.
- Use Export Data regularly to save a backup JSON file.
